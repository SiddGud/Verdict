Fans shouldn't have to choose.

A clash is two acts that share many fans, playing at the same time on different stages: someone misses one. Clash Court uses Qloo's taste data to find every clash, and AI agents put each one on trial and fix it without breaking the festival's rules.

  1. Pick a festival day in the bar above, or bring your own lineup.
  2. Press Convene the court. AI agents argue each clash: one speaks for each act's fans, a booker agent checks the rules, a judge rules.
  3. On the first case you are the booker: approve a move, let the clash stand, or let the judge decide. If you overrule, the agents argue the rest of the day live.
  4. Type an emergency like Tyla just cancelled, or drag any set on the timetable to move it yourself.

Why it matters

A $40 billion business runs on one question: who shares fans?

Every timetable, every booking date and every marketing plan in live music depends on which acts draw the same people. Today nobody puts a number on it before the tickets go on sale. Clash Court does, with Qloo.

    How the court works

    Who is in the room

    Code builds the timetable; the agents argue, object and explain. Nothing an agent says can move a set in a way that breaks a rule.

    1. The clerk reads the bill

      Every act is matched to Qloo by exact name. Qloo scores how much each pair's fans are the same people, for the whole bill.

    2. Fan agents file cases

      Every red clash becomes a case. Each act's agent looks up its fans and the moves that would help, and proposes one.

    3. The booker objects

      The booker agent checks each proposal against the rules and objects when it breaks one: headliners close, no act moves more than two hours, set lengths and stage sizes stay. It may offer a legal move instead.

    4. The judge rules

      The judge scores the proposals and rules. Code checks the move, makes it, and an optimiser tidies the rest of the day with the agents' moves kept.

    5. Emergencies

      Type "Tyla just cancelled" or "Kesha arrives at 4pm". The booker reads it into a checked rule and the timetable is rebuilt.

    6. Fans weigh in

      A fan's route flags the clashes they cannot avoid. Each report adds weight to that pair the next time the court sits.

    Two model families

    GPT-6 Astra and Gemini

    A frontier model and a small fast one, each run alone and with Qloo on the same questions, so the gain is Qloo's and not one model's quirk.

    Qloo alone and GPT-6 Astra alone are level on taste (Test 28: 0.723 and 0.697, not a significant gap), which is why Clash Court uses them together. Full protocols and readings: PREREGISTRATION_28.md and PROJECT_LOG.md.
